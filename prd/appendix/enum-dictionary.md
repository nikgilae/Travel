# Словарь перечислений и констант

## Backend — нативные Postgres ENUM

### `trip_purpose` (цель поездки)
| Значение | Русская метка (Dashboard `PURPOSE_LABEL`) |
|---|---|
| `leisure` | Отдых |
| `business` | Работа |
| `education` | Учёба |
| `other` | Другое |

### `budget_level` (уровень бюджета)
| Значение | Метка на Dashboard (`BUDGET_LABEL`) | Метка на экране маршрута (`budgetLabel`) |
|---|---|---|
| `low` | Экономно | ЭКОНОМНО |
| `medium` | Комфортно | КОМФОРТНО |
| `high` | Люкс | ЛЮКС |

### `poi_status_enum` (статус точки в поездке)
| Значение | Описание |
|---|---|
| `main` | Основная точка дня |
| `additional` | Запасная/альтернативная точка |

## Frontend — онбординг

### Шаг «Бюджет» → `BUDGET_MAP` (App.jsx)
| UI-значение | Отправляется в API как |
|---|---|
| `economy` | `low` |
| `comfort` | `medium` |
| `lux` | `high` |

### Шаг «С кем вы» → `GROUP_SIZE_MAP`
| UI-значение | `group_size` |
|---|---|
| `solo` | 1 |
| `duo` | 2 |
| `friends` | 3 |
| `family` | 4 |
| `group` | 6 |

### Шаг «В каком стиле» — интересы (`STYLES`, свободный многовыбор)
`relaxed`, `active`, `cultural`, `food`, `nature`, `night` — отправляются как есть в поле `interests` при генерации маршрута.

### Ритм поездки (`rhythmLabel`, вычисляется на экране маршрута)
> Примечание: фактически всегда `balanced`, т.к. шаг выбора ритма (`OnboardingStep3`) не подключён к роутингу.

| Значение | Короткая метка | Развёрнутая |
|---|---|---|
| `slow` | СПОКОЙНО | НЕ СПЕША |
| `intense` | НАСЫЩЕННО | АКТИВНО |
| `balanced` (default) | СБАЛАНСИРОВАННО | В РИТМЕ |

### Группа на экране маршрута (`groupLabel`)
`{solo:'СОЛО', duo:'ВДВОЁМ', family:'СЕМЬЯ', friends:'ДРУЗЬЯ', group:'ГРУППА'}`

## Прочие константы

- `TOP9` (Шаг 1 онбординга — приоритетный список стран): Турция, Китай, ОАЭ, Абхазия, Таиланд, Египет, Беларусь, Казахстан, Армения.
- `MAX_DAYS = 21` — максимальная длина поездки в календаре дат онбординга (мягкое предупреждение, не жёсткая блокировка).
- `ENRICH_COOLDOWN_HOURS = 24` (backend, `settings`) — минимальный интервал между авто-обогащениями города данными Google Places.
- `MAX_POIS_FOR_AI = 100` (backend) — максимум точек, передаваемых в промпт генерации.
- `ACCESS_TOKEN_EXPIRE_MINUTES = 180` — время жизни JWT.
- Пароль (регистрация): минимум 12 символов, ≥1 заглавная, ≥1 строчная, ≥1 цифра, ≥1 спецсимвол (проверяется и на фронте — живой чек-лист, и на бэкенде — Pydantic-валидатор).

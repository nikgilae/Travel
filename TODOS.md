## TODO-2: Заземление свободного чата базой POI
- **What:** `POST /chat/general` и свободные текстовые ответы WS-агента должны рекомендовать только места из базы POI (или явно помечать внешние знания).
- **Why:** Ключевое обещание продукта «без галлюцинаций» код обеспечивает только в генерации маршрута (`backend/app/services/ai.py`); свободный чат — незаземлённый LLM (P5 design doc волны 1).
- **Pros:** Обещание продукта становится честным на всех поверхностях.
- **Cons:** Заметная работа: промпты, выборка POI по контексту, оценка качества.
- **Context:** Транскрипты волны 1 покажут, как часто чат называет места вне базы — они и приоритезируют эту работу.
- **Depends on:** Транскрипты волны 1 (T4).

## TODO-4: Session replay / PostHog при росте N
- **What:** Подключить PostHog (события фронта + session replay), когда пользователей станет >20.
- **Why:** Replay — ближайшая удалённая замена «смотреть через плечо»; при N<10 дашборды — шум (решение design doc волны 1, Approach B).

- **Context:** Отклонено для волны 1 в пользу консьержа + чёрного ящика.
- **Depends on:** Рост N > 20.

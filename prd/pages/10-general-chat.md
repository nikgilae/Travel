# Общий чат

> **Роут:** `/dashboard/chat`
> **Модуль:** AI-чат
> **Файл:** `frontend/src/pages/GeneralChatPage.jsx` → тонкая обёртка над `src/components/ChatScreen.jsx` (`mode="general"`, тёмная тема)

## Обзор
Свободный чат с AI-ассистентом, не привязанный к конкретной поездке — для общих вопросов о путешествиях (куда поехать, нужна ли виза, какой бюджет заложить) до создания маршрута.

## Layout
Стандартный чат-интерфейс: лента сообщений → чипсы с предложенными вопросами → поле ввода + кнопка отправки.

## Взаимодействия

### Отправка сообщения
- **Триггер:** ввод текста + отправка
- **API:** `POST /chat/general` `{message, history: [{role, content}, ...]}` (Bearer) → `{reply}`
- **Поведение:** история хранится только в состоянии компонента (в памяти), **не сохраняется между перезагрузками страницы**

### Чипсы-подсказки
Предложенные вопросы: «Куда поехать в мае?», «Нужна ли виза в Турцию?», «Бюджет на неделю в Италии» — клик подставляет текст в поле ввода/сразу отправляет.

## API-зависимости

| API | Метод | Путь | Триггер | Примечания |
|---|---|---|---|---|
| Общий чат | POST | `/chat/general` | Отправка сообщения | Без tool calling; `max_tokens=600`; история усекается до последних 20 сообщений на бэкенде |

## Связи со страницами
- **Откуда:** Дашборд (таб-бар, пустое состояние)
- **Куда:** таб-бар → `/dashboard/routes`, `/dashboard/nearby`

## Бизнес-правила / замечания
- Ассистент не использует контекст конкретной поездки и не может менять маршрут — только текстовые ответы.
- Все сообщения (пользователя и ассистента) пишутся backend'ом в таблицу `messages` в фоне (best-effort, не блокирует ответ), но **эта история никогда не читается обратно приложением** — чисто журнал для аналитики/отладки, не для восстановления диалога.

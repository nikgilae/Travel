# Дашборд («Мои маршруты»)

> **Роут:** `/dashboard/routes`
> **Модуль:** Поездки
> **Файл:** `frontend/src/pages/DashboardPage.jsx` (+ `.css`), обёрнут в `DashboardLayout` (тёмная тема, нижний таб-бар)

## Обзор
Главный экран для вернувшегося пользователя со списком уже созданных поездок. Позволяет создать новую поездку, открыть существующую или удалить её.

## Layout
- Хедер: логотип + кнопка профиля (`ProfileButton`, аватар — первая буква email)
- CTA «＋ Создать маршрут»
- Список карточек поездок (или скелетоны при загрузке / баннер ошибки / пустое состояние)

## Поля / элементы

### Регион: «Карточка поездки» (`TripCard`)
| Элемент | Формат | Источник |
|---|---|---|
| Город | Текст | `trip_meta[trip.id].cityName` из localStorage (фолбэк — «Маршрут») |
| Цель поездки | Метка | `PURPOSE_LABEL[trip.purpose]` |
| Кол-во дней | Бейдж | Вычисляется из `start_date`/`end_date` |
| Группа / бюджет | Чипсы | `groupLabel(group_size)`, `BUDGET_LABEL[budget]` |
| Диапазон дат | Форматированный текст | `start_date` — `end_date` |
| Выбор (чекбокс) | `SelectionCircle` | Локальное состояние `selectedTrips` |
| Удалить | Иконка корзины | Открывает `ConfirmDeleteModal` |
| Открыть | Кнопка «Открыть →» | Переход на `/trip/{id}/plan` |

### Регион: «Профиль» (`ProfileButton`, выпадающее меню)
- Email пользователя
- «Выйти»

## Взаимодействия

### Загрузка страницы
- **API:** `GET /trips` (Bearer) → список поездок пользователя

### Создание поездки
- **Триггер:** «＋ Создать маршрут» (или CTA в пустом состоянии)
- **Действие:** переход на `/onboarding`

### Удаление поездки
- **Триггер:** иконка корзины на карточке
- **Поведение:** открывает `ConfirmDeleteModal` → подтверждение → `DELETE /trips/{id}` (Bearer) → карточка исчезает с fade-out анимацией

### Открыть поездку
- **Триггер:** «Открыть →»
- **Действие:** переход на `/trip/{id}/plan`, в `location.state` передаются кэшированные `city`/`groupType`/`rhythm`

### Выход
- **Триггер:** «Выйти» в меню профиля
- **Действие:** очищает `access_token`, `user_email` из localStorage → переход на `/`

### Пустое состояние
- Заголовок «Пока пусто» + две CTA: «Создать маршрут» (`/onboarding`) и «Открыть чат» (`/dashboard/chat`)

## API-зависимости

| API | Метод | Путь | Триггер |
|---|---|---|---|
| Список поездок | GET | `/trips` | Монтирование страницы |
| Удалить поездку | DELETE | `/trips/{id}` | Подтверждение удаления |

## Связи со страницами
- **Куда:** `/onboarding`, `/trip/{id}/plan`, `/dashboard/chat`, `/dashboard/nearby`, `/` (после выхода)

## Бизнес-правила / замечания
- **[Незавершённая функциональность]** Множественный выбор карточек (`selectedTrips`, чекбоксы `SelectionCircle`) реализован в состоянии компонента, но ни одно массовое действие (например, «удалить выбранные») к нему не привязано — UI-заготовка без логики.
- Название города на карточке зависит от локального кэша `trip_meta`; если пользователь открыл дашборд на новом устройстве/после очистки localStorage, карточки покажут фолбэк «Маршрут» вместо реального названия города, так как `GET /trips` не возвращает связанные объекты страны/города (только UUID/базовые поля поездки — уточнение: `TripResponse` не включает вложенные `country`/`city`, только `country_id`/`city_id`).

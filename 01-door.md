**Проблема, которую ты сам назвал, и она настоящая.**

`frontend/src/App.jsx:162` — маршрут `/` отдаёт `LoginPage`. Человек, которому ты
кинул tourrhythm.ru в директ, открывает с телефона форму «email / пароль» и не
понимает, куда попал. Он не бросает продукт — он до продукта не доходит.

Пока это так, любая работа по модулю 02 сгорает: ты потратишь 20 самых тёплых
контактов на дверь, которая выглядит как чужой замок.

## Что построить

Один экран. Не сайт.

```
┌─────────────────────────────┐
│  TourRhythm                 │
│                             │
│  Маршрут по дням для твоей  │  ← одна строка, что это
│  поездки. Только реальные   │
│  места — не выдуманные.     │
│                             │
│  [ гиф/видео из демо ]      │  ← у тебя уже записано (21.07)
│                             │
│  ┌───────────────────────┐  │
│  │  Собрать маршрут      │  │  ← главная кнопка → /register
│  └───────────────────────┘  │
│                             │
│  Уже есть аккаунт → Войти   │  ← мелко, вторично
└─────────────────────────────┘
```

Технически: новый `LandingPage` на `/`, `LoginPage` переезжает на `/login`,
поправить редиректы в `ProtectedRoute` и после регистрации. Всё.

## Чего НЕ делать

Цены, отзывы, FAQ, футер, «о нас», форму подписки, счётчик пользователей, блог,
секцию «как это работает» из шести шагов. Каждый из этих блоков — способ отложить
разговор с живым человеком. Их время придёт, когда трафик пойдёт не из твоего
директа.

## Обязательные требования

- **Мобильный экран первым.** 100% твоего трафика — люди, открывающие ссылку из
  Instagram с телефона. Проверять на телефоне, не в десктопном браузере.
- **Видео/гиф весит мало и играет без клика.** Демо у тебя записано — из него
  нужен один фрагмент: как из пустого экрана появляется маршрут по дням. Это
  единственное, что продаёт.
- **Превью ссылки (og:image + og:title).** Когда ты кидаешь ссылку в директ,
  Instagram показывает карточку. Сейчас там, скорее всего, пусто. Это половина
  доверия в первую секунду.

## Текст первого экрана

Одна строка. Кандидаты — выбери один, не составляй из них абзац:

- «Маршрут по дням для твоей поездки. Все места — настоящие, проверены по картам.»
- «Как ChatGPT для поездки, только места не выдуманные — их можно открыть в картах.»
- «Собирает маршрут на каждый день поездки из мест, которые реально существуют.»

Второй вариант — про то, что ты сам описал: девушка из рилса ходит в ChatGPT, потом
перепроверяет каждое место в Google Maps, потом переписывает в ежедневник. Ты
убираешь второй и третий шаг. Это и есть продукт, и это уже правда в коде —
генерация выбирает из POI базы (`backend/app/services/ai.py`), а не сочиняет.

Осторожно: в свободном чате это обещание пока не выполняется — чат не заземлён
базой (`TODOS.md`, TODO-2). Значит на лендинге обещай про **маршрут**, не про
«ассистента, который никогда не врёт».

## Готово, когда

Ты отправляешь ссылку человеку, который не знает о продукте ничего. Он с телефона
за 15 секунд понимает, что это, и жмёт кнопку. Проверка — на живом человеке, не на
себе. Спроси одного из 20: «открой и скажи одной фразой, что это». Если он
пересказал неправильно — виноват текст, не он.

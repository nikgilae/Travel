# Рядом

> **Роут:** `/dashboard/nearby` (без контекста поездки) и `/trip/:id/nearby` (в контексте поездки)
> **Модуль:** POI
> **Файл:** `frontend/src/pages/NearbyPage.jsx` (+ `.css`) — один и тот же компонент для обоих роутов

## Обзор
Поиск мест рядом с текущим геопозиционированием пользователя в реальном времени через прокси Google Places. Используется как самостоятельная вкладка дашборда и как вкладка внутри конкретной поездки (в последнем случае добавляется возможность быстро отправить найденное место в чат поездки).

## Layout
Заголовок → блок фильтров (горизонтальные чипсы) → список карточек мест (или скелетоны/пустое состояние/состояние ошибки геолокации).

## Поля / элементы

### Фильтры (`FILTERS`)
Все / Поесть / Культура / Погулять / Кофе / Шоппинг / Развлечения — маппятся на параметр `type` Google Places (см. [enum-dictionary](../appendix/enum-dictionary.md)).

### Карточка места (`PlaceCard`)
| Элемент | Источник |
|---|---|
| Название | Google Places |
| Расстояние | Вычисляется на клиенте по формуле Haversine от текущей геопозиции |
| Тип (метка) | `TYPE_LABELS[placeTypeLabel(types)]` |
| Рейтинг | Google Places `rating` |
| Открыто/закрыто | `opening_hours.open_now` |
| Адрес | `vicinity`/`formatted_address` |
| «ОТКРЫТЬ ↗» | Внешняя ссылка на Google Maps по `place_id` |
| «В ЧАТ →» | Только если есть `tripId` — переход в чат поездки с предзаполненным сообщением |

## Взаимодействия

### Геолокация
- `navigator.geolocation.getCurrentPosition` при монтировании (таймаут 10с, max age 60с)
- Состояния: `idle` → `requesting` → `ok` / `denied`
- При отказе — кнопка «РАЗРЕШИТЬ ДОСТУП» для повторного запроса

### Загрузка мест
- **API:** `GET /places/nearby?lat&lon&radius=1000[&type=...]` (Bearer, с `AbortController` для отмены при смене фильтра)
- Перезапускается при получении геопозиции или смене фильтра
- Результаты сортируются на клиенте по расстоянию (haversine), независимо от порядка бэкенда

### «В ЧАТ →» (только в контексте поездки)
- **Триггер:** клик на кнопку карточки
- **Действие:** `navigate('/trip/{tripId}/chat', {state: {prefill: 'Добавь "{name}" в мой маршрут'}})`

## API-зависимости

| API | Метод | Путь | Триггер | Примечания |
|---|---|---|---|---|
| Места рядом | GET | `/places/nearby` | Получение геопозиции / смена фильтра | Прокси к Google Places Nearby Search, `language=ru` |

## Связи со страницами
- **Откуда:** таб-бар Дашборда (`/dashboard/nearby`) или таб-бар поездки (`/trip/{id}/nearby`)
- **Куда:** `/trip/{id}/chat` (только из контекста поездки, с предзаполнением)

## Бизнес-правила / замечания
- Кнопка «В ЧАТ →» скрыта, если страница открыта без `tripId` (вне контекста поездки).
- Найденные места **не сохраняются** ни в БД, ни в маршрут напрямую — единственный способ добавить их в поездку — попросить AI-ассистента через чат.

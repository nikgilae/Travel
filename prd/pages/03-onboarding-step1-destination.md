# Онбординг — Шаг 1: «Куда едем?»

> **Роут:** `/onboarding` (внутренний шаг 1 из 6, компонент `OnboardingFlow` в `App.jsx`)
> **Модуль:** Онбординг
> **Файл:** `frontend/src/pages/OnboardingStep1.jsx` (+ `.css`)
> **Контекст:** `OnboardingContext` (`src/store/onboardingStore.jsx`) — не персистится, живёт только пока открыт онбординг

## Обзор
Первый и обязательный шаг: выбор страны и города путешествия. Двухфазный интерфейс — сначала список/поиск стран, затем список/поиск городов выбранной страны.

## Layout
- Заголовок «КУДА ЕДЕМ?»
- Фаза 1 (страны): поле поиска + приоритетная секция «Топ-9» популярных стран + алфавитный список остальных, карточки с процедурно генерируемыми SVG-иллюстрациями (детерминированный хеш названия → палитра/силуэт — реальных фото нет)
- Фаза 2 (города, открывается после выбора страны): поле поиска + сетка городов; если введённый текст не совпадает ни с одним реальным городом — предлагается создать «кастомный» город

## Взаимодействия

### Загрузка страницы
- `GET /countries` (Bearer) → список стран → рендер «Топ-9» + остальные по алфавиту

### Выбор страны
- Лениво подгружает `GET /countries/{id}/cities`, результат кешируется в памяти компонента на время сессии онбординга
- Переключает UI в фазу выбора города

### Поиск города / кастомный город
- Свободный текстовый ввод фильтрует список городов
- Если совпадений нет — предлагается создать клиентский «кастомный» город: `city_id: null`, `isCustom: true` (проходит regex-валидацию свободного текста)

### Продолжить
- **Триггер:** нажатие «Продолжить» после выбора города
- **Действие:** передаёт `{n, sub, days, code, cityId, countryId}` наверх в `App.jsx`, который вызывает `update({city_id, country_id})` в `OnboardingContext`
- **Переход:** к Шагу 2 (С кем вы)

## API-зависимости

| API | Метод | Путь | Триггер |
|---|---|---|---|
| Список стран | GET | `/countries` | Монтирование страницы |
| Города страны | GET | `/countries/{country_id}/cities` | Выбор страны |

## Связи со страницами
- **Куда:** Шаг 2 онбординга (С кем вы)

## Бизнес-правила / замечания
- Иллюстрации стран — не реальные фото, а генерируемые на клиенте SVG (нет интеграции с фото-API для стран).
- Кастомный город (`city_id: null`) может привести к проблемам на бэкенде при создании поездки — `TripCreate.city_id` ожидает существующий UUID; сценарий работы с кастомным городом до конца поездки не прояснён кодом (`[TBC]`).

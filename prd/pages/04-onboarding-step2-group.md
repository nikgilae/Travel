# Онбординг — Шаг 2: «С кем вы?»

> **Роут:** `/onboarding` (шаг 2 из 6)
> **Модуль:** Онбординг
> **Файл:** `frontend/src/pages/OnboardingStep2.jsx` (+ `.css`)

## Обзор
Выбор состава группы путешествия — определяет `group_size`, передаваемый при создании поездки.

## Layout
Заголовок «С КЕМ ВЫ?» → карточки-варианты (radio-выбор) → опциональное текстовое поле «заметка» → кнопки «Продолжить» / «Пропустить».

## Поля

| Поле | Тип | Обязательное | Опции | По умолчанию |
|---|---|---|---|---|
| Тип группы | Карточки (одиночный выбор) | Нет (есть «Пропустить») | `solo`, `duo`, `family`, `friends`, `group` | `duo` |
| Заметка | Текстовое поле (textarea) | Нет | Свободный текст | — |

## Взаимодействия

### Выбор и продолжение
- **Триггер:** нажатие «Продолжить»
- **Действие:** `App.jsx` мапит выбор через `GROUP_SIZE_MAP` (`solo:1, duo:2, family:4, friends:3, group:6`) → `update({group_size})`
- **Переход:** к Шагу 3 (Когда едем)

### Пропустить
- **Триггер:** «Пропустить»
- **Действие:** отправляет `(null, '')` — `group_size` не устанавливается явно на этом шаге (в контексте остаётся значение по умолчанию `1`)

## API-зависимости
Нет прямых вызовов API — шаг только накапливает данные в `OnboardingContext`.

## Бизнес-правила / замечания
- **[Незавершённая функциональность]** Текстовая заметка о попутчиках собирается в локальном состоянии компонента, но **никуда не отправляется** — ни в `OnboardingContext`, ни на бэкенд. Поле присутствует в UI, но результат теряется.
